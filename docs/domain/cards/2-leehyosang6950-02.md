# 2-leehyosang6950-02 연장·야간·휴일근로는 통상임금의 50% 이상 가산해서 지급한다

| 항목 | 내용 |
| --- | --- |
| 관점 | ② 규칙·예외 |
| 자료 종류 | 법령 |
| 제목·저자(기관)·연도 | 근로기준법 제56조(연장·야간 및 휴일 근로), 2018.3.20 개정 반영 조문 |
| 찾은 곳·링크 (DOI) | 해설 사이트에서 확인함: https://korea.legal/wiki/근로기준법-제56조/ → 법제처 국가법령정보센터에서 현행 조문 재확인 필요 (DOI 없음) |
| 직접 확인 | ☑ 직접 열어 확인함 · 확인한 위치: 제56조 1항·2항·3항 |
| 확인한 내용 | 1항: 연장근로는 통상임금의 100분의 50 이상 가산. 2항: 휴일근로는 8시간 이내 100분의 50, 8시간 초과 100분의 100. 3항: 야간근로(오후 10시~다음 날 오전 6시)는 100분의 50 이상 가산 |
| 우리 도메인에 주는 근거 한 줄 | "야근 수당 안 주는 회사" 상황 카드와 짝지을 핵심 법 카드이며, 연장·휴일·야간 기준이 달라 법 카드가 여러 장 필요하다 |
